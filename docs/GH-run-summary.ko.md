## 오류 원인

```text
ValueError: Encoder length exceeded; refusing silent truncation
```

후보 생성은 문장 끝을 두 번 인식할 때까지 이어질 수 있지만, 임베딩 인코더의 입력 상한은 **4,096토큰**입니다. MMLU와 SuperGPQA에서 긴 후보가 이 상한을 넘으면서 실행이 중단되었습니다. GPU 메모리 부족 오류는 아닙니다.

같은 설정으로 재개하면 동일한 오류가 다시 발생할 것으로 예상됩니다. 인코더·메모리 제한을 함께 조정하거나 긴 후보의 처리 방식을 수정해야 합니다.
